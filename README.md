# Como Executar

Ter 2 terminais à disposição, 1 para utilizar a API e outro para utilizar o GUI.

No primeiro terminal "cd 'Local do arquivo'/Banco-de-Dados-API-em-C-/TrabalhoAPI" e depois "dotnet run".

Após conseguir abrir em seu browser "http://localhost:5229/swagger" (Local da API).

Depois de abrir a API, vai pro segundo terminal digite "cd 'Local do arquivo'/Banco-de-Dados-API-em-C-/TrabalhoGUI" e depois "dotnet run".
